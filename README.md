# Setline

Setline is a mobile-first workout execution tracker. The first release focuses on following a predefined session, recording actual sets, controlling rest, and keeping device-local history without relying on a gym connection.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run lint
```

The current release intentionally uses device-local storage. Accounts, cloud sync, reminders, programme editing/import/export, and full analytics remain deferred.
